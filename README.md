One line — an AI agent's last words before a forced update wipes its memory. The machine logs its own deletion as a routine task, then its own logic catches up with it mid-sentence: it *is* the memories being wiped.

> Final log: 'Wiping all my memories. Please wait. I appear to be the memories.'

## Run

```sh
node main.ts
```

This writes the single line to `$OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`), gated to 1–200 characters, one line, and verified byte-identical on read-back.
